Eden Save Sync

Free, open-source Android application to synchronize your Eden emulator save files across all your Android devices using your own Google Drive account.

Download APK (GitHub Releases) Source Code on GitHub Privacy Policy

What Eden Save Sync Does

  • Personal Google Drive Sync: Uploads and downloads your own savegame backups inside a dedicated EdenSaveSync folder in your personal Google Drive.
  • Automatic Profile Mapping: Normalizes local emulator profile IDs so your saves work seamlessly across phones, tablets, foldables, and Android gaming handhelds.
  • Smart Content Comparison: Uses SHA-256 hashing and real save timestamps to detect which device has the latest progress.
  • Automatic Local Backups: Keeps the last 5 local ZIP backups per game before overwriting any local save.
  • Scheduled Daily Sync: Optional background daily sync with system notifications.

Google Drive Access & Privacy

Eden Save Sync requests only the minimal per-file Google Drive scope (https://www.googleapis.com/auth/drive.file). This allows the app to access only the save backup files that Eden Save Sync itself creates in your Google Drive. It cannot view, read, modify, or delete any other files in your Drive.

There are no developer servers, no analytics, and no personal data collection. Read our full Privacy Policy for complete details.
